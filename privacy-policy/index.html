Privacy Policy

Fumeto Reader Plus (package name com.fumeto.reader) for Android, and as a Linux desktop app (beta)
Effective date: November 4, 2026 (previous version: November 3, 2026)
Source code: github.com/fumetodev/FumetoReaderPlus

The short version: Fumeto Reader Plus is a free, open-source, local-first app. It has no user accounts, no advertising, no purchases, and no analytics or tracking, and the developer operates no servers that receive your data. Your comics, books, reading progress, settings, and translations stay on your device. The app only communicates over the network with services you explicitly configure — such as your own media server or your own translation provider — with the host it downloads its optional AI model files from, with the websites you open in its built-in web browser, and, in the desktop version only, with GitHub to learn whether a newer release exists.

Who we are

Fumeto Reader Plus is developed and published by an independent developer. For any privacy question or request, contact: fumetoreaderdev@gmail.com.

The app is open source under the GNU GPL v3. Its complete source code is published at github.com/fumetodev/FumetoReaderPlus, so every statement in this policy can be checked against the code that ships.

Data stored on your device

The app stores the following information locally on your device only:

  • Comic and e-book files and libraries you import or create, and their metadata;
  • Reading progress and library organization;
  • App settings and preferences;
  • Translations generated for your pages, and any edits you make to them;
  • Optional server addresses and credentials you enter for your own media server (see below);
  • Optional API keys you enter for a translation provider (see below);
  • AI model files you download or import for on-device translation (see “Component downloads”);
  • The built-in web browser’s cookies, site storage and cache, kept apart from the rest of the app’s data; the address, title and site icon of each tab you leave open and each page you bookmark; and, for chapters you save from a website, their title, the addresses they were read from, the addresses of their page images, the site’s icon, their translations and a fingerprint (a hash) of each page image — never the page images themselves (see “Built-in web browser”);
  • Local diagnostic logs (see “Diagnostics and error reports”).

Credentials and API keys are encrypted at rest with a key that never leaves the device. None of this data is transmitted to the developer. You can delete it at any time by removing items in the app (downloaded models have their own delete button in Settings), clearing the app’s data in Android settings, or uninstalling the app.

The Linux desktop version keeps everything listed above in one folder in your home directory, ~/.local/share/com.fumeto.reader/: the library index, settings, downloaded model files, encrypted credentials and the local diagnostic log. The only other thing it writes is the web engine's small cookie store under ~/.cache/com.fumeto.reader/. Deleting those two folders together with the app file removes all of it.

Network features you control

All network features are optional and disabled until you configure or confirm them. When you use them, data goes only to the destination you chose:

  • Your own media server. If you connect a self-hosted comic server (such as Komga, Kavita, or YACReaderLibraryServer), the address and credentials or API key you enter are stored on your device and sent only to that server, in order to browse and fetch your comics from it. The developer never receives them. If you enter a plain http:// address, traffic to that server — including your credentials — is not encrypted on the way there; use https:// where your server offers it.
  • Translation with a provider or server you choose. The app can translate pages entirely on your device. No provider is set up when you install it, so no page content goes anywhere until you configure one. If you configure a translation provider — a cloud service under your own API key (for example an OpenRouter account, an Anthropic API key, or any OpenAI-compatible endpoint), or a server you run yourself on your own network (for example Ollama or LM Studio) — then the pages you choose to translate — the page image and/or the text extracted from it, depending on the model — are sent to that destination under your own account and are subject to its privacy policy. Any key you enter is stored on your device and sent only to that provider. If you only use on-device translation, no page content ever leaves your device.
  • Component downloads. Reading text off a page needs model files that are not included in the app itself: text detection and recognition models and a page-layout model, used by every translation mode, plus the translation model you pick if you translate on-device, and an optional sound-effect model if you choose to download it. They are downloaded from Hugging Face (huggingface.co) only after you confirm the download — the first time you translate a page, or when you choose a model in Settings. As with any download, the hosting service can see standard web request metadata such as your IP address. No personal content is sent. A model file you import from your own storage instead is copied into the app’s private storage and is never uploaded anywhere.
  • Built-in web browser (Android). The app includes a web browser, opened from the Tabs screen. The websites you open are contacted directly by your device, as in any browser: they see your IP address and the browser’s requests, may set their own cookies and show their own content, and their own privacy policies apply. Text you type that is not a web address is sent as a search to the search engine you choose in Settings (DuckDuckGo by default; Google, Bing or Startpage). When you choose to read the comic pages a website shows, the app downloads those page images from that website, with the browser’s cookies for it, and keeps them only while the chapter is open; translating them works like any other page (see above), so with a translation provider they are sent to that provider. Opening a saved chapter downloads its page images again from the addresses it remembers and, if those no longer work, loads its page on the website. Tabs you leave open come back when you restart the app, and a tab’s page is loaded only when you open it, so no website is contacted at launch. To block ads, the browser downloads two public block lists — EasyList (easylist.to) and AdGuard’s DNS filter (adguardteam.github.io) — when it is first used and about once a week after that while you use it; these requests carry no personal content. Android System WebView’s Safe Browsing protection, which checks addresses against Google’s list of dangerous sites, is on. The browser’s cookies, site storage and cache are kept on your device, separate from the rest of the app’s data, and Settings → Libraries → Web browser clears them and closes your open tabs; bookmarks and saved chapters stay until you delete them. The developer receives none of this.
  • Update notice (desktop version only). The Linux desktop version asks GitHub (api.github.com) at most once a day whether a newer release has been published, so that it can show a notice with a download link. The request carries no account, identifier or content — only the standard web request metadata any website sees, such as your IP address — and GitHub’s privacy statement applies to it. You can switch the automatic check off in Settings and check by hand instead. The Android app never makes this request.

Diagnostics and error reports

The app keeps a small, recent log of technical errors on your device to help diagnose problems. It is never transmitted automatically, and the app contains no crash-reporting service. If you choose to copy a diagnostic report to share (for example, when reporting a bug), the report is designed to contain only technical information — app version, device model (on desktop: operating system, graphics driver and display type), error messages — and to exclude comic titles, file names, page content, and any credentials or API keys.

What we don’t do

  • No user accounts or sign-in;
  • No in-app purchases or subscriptions — the app is entirely free and contains no billing library;
  • No advertising and no advertising SDKs or identifiers;
  • No analytics, telemetry, crash reporting, or tracking;
  • No sale or sharing of personal data — the developer holds no user data to sell or share;
  • No collection of location, contacts, or other device data unrelated to reading comics and books.

Permissions

The app declares the following Android permissions, and nothing else:

  • Internet — for the optional features, the built-in web browser and the model downloads described above.
  • Foreground service and wake lock — to keep a long batch translation, or a loaded on-device translation model, running while the app is in the background. Android shows a notification whenever such a service is running.
  • Notifications — the progress notification for a batch translation (which names the volume being translated) and a notification while the on-device model is loaded. Both are shown on your device only. Android asks you before the app can show them; if you decline, the features still work and the notifications are simply hidden.
  • Vibrate — brief haptic feedback for reader gestures.

The app requests no storage, photo, camera, microphone, location, or contacts permission. It reads the files you select through the Android file picker, and archives you copy into its own folder on external storage (Android/data/com.fumeto.reader/files/Comics), which it moves into your library on the next scan. Everything else it stores lives in its private app storage.

The Linux desktop version has no permission system of this kind. It reads the files and folders you choose in its file dialog or drop onto its window, saves exports where you tell it to, and keeps its own data in the folder named above.

Children

Fumeto Reader Plus is a general-audience utility and is not directed at children under 13.

Your rights

Because the developer does not collect or hold your personal data, requests to access or delete data are fulfilled directly on your device: all app data can be viewed inside the app and removed by deleting items, clearing app data, or uninstalling. For anything else, contact the email address above.
